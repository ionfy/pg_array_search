# pg_array_search

Расширение для PostgreSQL, реализующее набор функций для поиска, индексации и фильтрации внутри массивов

## Сборка

Для сборки и установки используйте команду:
```bash
make && make install
```
Для запуска тестов используйте команду:
```bash
make installcheck
```

Или запустите скрипт install_and_test.sh

## Функции

#### array_contains ( anyarray, anyelement ) → boolean
- Проверка наличия заданного элемента в массиве.
- При передаче NULL в качестве первого аргумена возвращает NULL.
- Вторым аргументом может быть NULL - функция корректно проверит его наличие в массиве.

#### array_contains_all ( anyarray, anyarray ) → boolean
- Проверка полного вхождения элементов второго массива в первый.
- При передаче NULL в качестве хотя бы одного из аргументов возвращает NULL.
- Второй аргумент внутри массива может содержать NULL - функция корректно проверит его наличие в массиве.

#### array_find_all ( anyarray, anyelement ) → integer[]
- Поиск всех вхождений заданного элемента в массив.
- При передаче NULL в качестве первого аргумена возвращает NULL.
- Вторым аргументом может быть NULL - функция корректно проверит его наличие в массиве.

#### array_filter ( anyarray, text ) → anyarray
- Фильтр элементов по условию ([предикату](#предикаты)).
- При передаче NULL в качестве хотя бы одного из аргументов возвращает NULL.

#### array_reject ( anyarray, text ) → anyarray
- Удаление элементов массива, удовлетворяющих условию ([предикату](#предикаты)).
- При передаче NULL в качестве хотя бы одного из аргументов возвращает NULL.

#### array_partition ( anyarray, text ) → anyarray
- Разделение массива на два: элементы, удовлетворяющие условию ([предикату](#предикаты)), и не удовлетворяющие.
- При передаче NULL в качестве хотя бы одного из аргументов возвращает NULL.

#### array_index_of ( anyarray, anyelement ) → integer
- Поиск индекса первого вхождения элемента в массив.
- Если значение отсутствует в массиве возвращает -1.
- При передаче NULL в качестве первого аргумена возвращает NULL.
- Вторым аргументом может быть NULL - функция корректно проверит его наличие в массиве.

#### array_last_index_of ( anyarray, anyelement ) → integer
- Поиск индекса последнего вхождения элемента в массив.
- Если значение отсутствует в массиве возвращает -1.
- При передаче NULL в качестве первого аргумена возвращает NULL.
- Вторым аргументом может быть NULL - функция корректно проверит его наличие в массиве.

## Предикаты
Параметры типа text, используется для написания условий отбора элементов массива.
Имеют следующий вид:

1. `'x op Const'` - логическая операция над элементом массива и константой.
2. `'x % Const = Const'` - операции взятия остатка от деления элемента массива на константу и сравнения результата.
3. `''` - пустая строка, любой элемент массива пройдет отбор через такой предикат.

**x** - переменная, обозначающая элемент массива.
- **Допустимые значения:** Последовательность строчных латинских букв a–z произвольной длины, без пробелов и иных символов.
- **Пример:** x, y, value, abc.

**op** - одна из доступных операций.
- **Допустимые значения:** >, >=, <, <=, =, ==, !=.

**Const** - константа, участвующая в операциях над элементами массива.
- **Допустимые значения:**
    - **Числовые:** представляет собой число положительное или отрицательное. Может как быть целым, так и иметь дробную часть.
    - **Строковые:** указываются в кавычках ("str").
- **Пример:** 1, 256, -10, 3.5, -9.9, "foo", "some str".

**Ограничения:**
- Тип элементов массива должен соответсвовать типу константы в предикате.
    - Нельзя сравнивать массив строк с числом.
    - Нельзя сравнивать массив чисел со строкой.
    - Нельзя сравнивать массив целых чисел с дробным числом.
- Второй вариант предиката допустим только для массивов с целыми числами, соответственно константы так же должны быть целыми.
- Для массивов строк допустимы только операции == и !=.

**Примеры:**
- **Допустимые значения предикатов:**
    - array_filter(ARRAY[1, 2, 3], 'x == 2')
    - array_filter(ARRAY[1.2, 1.3, 1.4], 'x > 1')
    - array_filter(ARRAY[1.2, 1.3, 1.4], 'x < 1.5')
    - array_filter(ARRAY[1, 2, 3], 'x % 2 = 1')
    - array_filter(ARRAY['ab', 'cd', 'ef'], 'x == "cd"')
    - array_filter(ARRAY[1, 2, 3], '')
- **Недопустимые значения предикатов:**
    - array_filter(ARRAY[1, 2, 3], 'some value > 1') - имя не должно содержать пробел
    - array_filter(ARRAY[1, 2, 3], 'x > 1.5') - нельзя сравнивать целые числа с дробными
    - array_filter(ARRAY[1.1, 1.2, 1.3], 'x % 2 = 1') - операция остатка от деления не доступна для дробных чисел
    - array_filter(ARRAY['ab', 'cd', 'ef'], 'x < "cd"') - для строк доступны только == и !=
    - array_filter(ARRAY[1, 2, 3], 'x == "2"') - нельзя сравнивать значения разных типов
    - array_filter(ARRAY[1, 2, 3], 'x + 1 = 2') - недоступная операция
    - array_filter(ARRAY[1, 2, 3], 'x') - не соответствует ни одному из вариантов предиката
    - array_filter(ARRAY[1, 2, 3], '4 == x') - не соответствует ни одному из вариантов предиката

## Ограничения
- Поддерживаются массивы только с числовыми и строковыми типами элементов
